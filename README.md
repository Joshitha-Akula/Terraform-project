# Infrastructure as Code (IaC) with Terraform

## Project Overview

This project demonstrates Infrastructure as Code (IaC) using Terraform.

The objective is to replace manual infrastructure configuration with a declarative Terraform configuration. The project demonstrates Terraform configuration, initialization, validation, planning, deployment, state management, and resource destruction.

## Objectives

- Understand Infrastructure as Code using Terraform.
- Create infrastructure using declarative configuration.
- Understand Terraform providers and resources.
- Use Terraform variables and outputs.
- Understand Terraform state management.
- Perform the complete Terraform lifecycle.
- Store the project in a GitHub repository.

## Technologies Used

- Terraform
- HashiCorp Terraform Provider
- HCL
- Git
- GitHub
- Visual Studio Code
